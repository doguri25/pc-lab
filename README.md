# PC LAB v2.3.0 — 컴퓨터 조립 시뮬레이터

배포일: **2026-09-14 / Asia/Seoul**

컴퓨터 초보자가 PC 부품을 직접 조립·분해하고, 호환성·제품명·규격·성능 용도·고장 진단을 학습할 수 있는 로컬 실행형 시뮬레이션 게임입니다.

## 실행

가장 간단한 방법은 저장소 루트의 `PC_LAB_v2.3.0.html`을 Chrome/Edge 계열 브라우저로 여는 것입니다.

개발 서버로 실행하려면 Node.js 18 이상에서:

```sh
npm start
```

## 주요 기능

- 일반 데스크톱, 미니 PC, 초소형 PC, 노트북, 일체형 PC
- 3D 회전 작업대와 드래그 기반 조립·분해
- 나사, RAM 걸쇠, PCIe 고정장치, 케이블, 써멀그리스 등 단계별 작업
- Intel/AMD CPU, GPU, RAM, 메인보드, 저장장치, 파워, 쿨러, 네트워크, 주변기기 데이터
- 소켓·메모리·PCIe·전력·폼팩터 등 호환성 검사
- 부품 사전과 초보자용 비유 중심 설명
- 고장 진단 의뢰, 가상 BIOS/UEFI, Windows/Linux 학습 화면
- 27개 활용 카테고리와 다양한 성능 활용 시나리오
- 테마, 글꼴, 글자 크기, 효과음, 수동/자동 저장 설정
- 오프라인 우선 단일 HTML 빌드

## v2.3.0 핵심 변경

- CPU/GPU/저장장치 외 모든 부품의 모델·규격 설명을 대폭 보강
- DDR5와 DDR4의 구조적 차이, 전압, PMIC, 서브채널, On-die ECC 설명
- ATX / microATX / Mini-ITX의 실제 크기와 확장성 비교
- AMD/Intel 메인보드 칩셋과 CPU 소켓 설명 강화
- 파워 용량, ATX/SFX/SFX-L 폼팩터, 효율과 용량의 차이 설명
- PCIe x1, HDMI, DisplayPort, 네트워크·쿨러 규격을 초보자 비유와 함께 설명
- 제조사/제품군/개별 모델/규격을 구분하는 상세 정보 구조 강화

## 개발·검수

```sh
npm test
node build.cjs
```

`CHANGELOG.md`와 `releases.json`이 버전·한국 날짜·변경 기록의 기준입니다.

## 저장과 개인정보

PC LAB은 로컬 실행을 우선합니다. 자동 저장은 사용자가 설정에서 켠 경우에만 활성화되며, 계정 동기화는 현재 정식 로컬 버전에 포함되지 않습니다.

## 라이선스

현재 저장소의 `package.json`은 `UNLICENSED`로 설정되어 있습니다. 별도 허가 없이 재배포·상업 이용 권한을 부여한다는 의미가 아닙니다.
