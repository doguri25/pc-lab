# PC LAB — 컴퓨터 조립 시뮬레이터

PC LAB은 부품을 직접 선택하고, 작업대를 관찰하고, 조립·분해·진단·BIOS/OS 가상 작업을 체험하는 오프라인 학습용 컴퓨터 조립 시뮬레이터입니다.

## 주요 기능

- 부품 선택과 호환성 확인
- 2D/3D 작업대 및 정밀 작업 화면
- 패널, 나사, RAM, GPU, 저장장치, 케이블 등 조립·분해
- BIOS/UEFI, Windows/Linux 설치 및 가상 드라이버·네트워크 작업
- 부품별 자세한 사양과 용어 설명
- 저장/불러오기, 진단, 가상 전원 및 부팅 흐름

## 실행

정적 웹앱이므로 GitHub Pages 또는 로컬 서버에서 실행할 수 있습니다.

```bash
npm install
npm start
```

또는 릴리스 HTML 파일을 브라우저에서 직접 열어 사용할 수 있습니다.

## 주의

교육용 시뮬레이터이며 실제 제조사 서비스 도면이나 실제 시스템 설정을 그대로 복제하는 용도가 아닙니다.
